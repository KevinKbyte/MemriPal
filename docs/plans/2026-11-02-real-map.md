# MemriPal: accurate real map, option A (item 22)

Decisions: ADR [0041](../decisions/0041-real-map-whole-file-pmtiles.md) (amends ADR 0038 map-source condition 2; ADR
0038 conditions 1 and 3-10 stand). Spec: MEM-074..MEM-078 (`.claude/spec-cache/memripal/references/spec-4.md`). IDs:
item 25 owns ADR 0040 + MEM-073. Kev approved downloads and the approach 2026-11-02.

Scope: real Kendall Square streets under `geo` routes, bbox `(-71.1083, 42.3494, -71.0719, 42.3764)`, zooms 12-14;
the SVG sketch (`static/route_map.js`) stays the fallback and `sketch`-route renderer. Folds item 18 (off-screen
landmarks not in the DOM). Non-goals: other places, a service worker, MapLibre 6, the design gate's route shots
(ADR 0038 condition 10).

Order: S1 -> S2 -> HOLD (Kev approves shots) -> S3 -> S4 -> S5; S6 after S4.
Gate per slice: `sh scripts/check.sh` green.

## S1 Extract + style scripts. MEM-074, MEM-075

- `scripts/build_map_extract.py` (PyPI `pmtiles` 3.8.1 `Reader` over HTTP Range on the planet, `Writer` in ascending
  tile id); `scripts/build_map_style.mjs` (vendored `@protomaps/basemaps` 5.7.2, `{lang: "en"}`); commit
  `static/map/kendall.pmtiles`, `static/map/style-light.json`, `static/map/style-dark.json`, `static/map/VERSION` lines.
  <!-- claim-exempt: planned -->
- CRITERIA: (1) fake-planet tests: tile count == bbox enumeration at z12-14, 0 tiles outside, bytes identical to source;
  (2) output header: magic `PMTiles`, version 3, zooms 12/14, bounds == bbox at e7; (3) committed extract <= 3,145,728
  bytes; (4) 0 network calls in pytest; (5) each style: >= 1 `symbol` layer with `text-field`, source url
  `pmtiles://kendall`, 0 `http(s)://` in `sources.*.url`/`glyphs`/`sprite`; (6) every `text-font` stack has a dir under
  `static/map/fonts`; (7) second style run byte-identical; (8) `static/map/VERSION` names the build key, bbox, zooms,
  extract sha256.
- SIGNALS: `builds.json` lists a reachable build key at run time (about one week retention).

## S3 Loader + fallback. MEM-076

- Loader module in `static/`; `static/route_view.js` mounts it on `#route-map` / `#recall-map` for in-bbox `geo` routes.
- CRITERIA: (1) fake-fetch tests: 404, HTML body with 200, body < 127 bytes, oversize -> sketch stays, 0 map
  instances; (2) valid archive -> 1 map instance; (3) 0 extract fetches before route-view entry; 1 per session after;
  (4) request has no `Range` header; (5) URL neither root-relative nor absolute; module imports no `api_base.js`;
  (6) dark theme -> `style-dark.json`, light -> `style-light.json`; (7) sketch in DOM until first `idle`.
- SIGNALS: none.

## S4 Overlay + markers + a11y + attribution. MEM-077 (item 18)

- One SVG overlay positioned via `map.project` on `move`; markers recomputed on `moveend`.
- CRITERIA: (1) every station overlay point within 1 px of `map.project` after 1 pan and 1 zoom; (2) marker DOM count
  == station count + in-viewport landmark count at 3 viewports (stations never culled, off-map ones pinned; culling
  is for off-route landmarks only, ADR 0038 rule 3; amended 2026-11-02, item 11); (3) map canvas container
  `aria-hidden="true"`; (4) attribution visible at 375 px; (5) 1 out-of-bbox station -> sketch, 0 extract fetches;
  (6) 0 route layers in either style.
- SIGNALS: none.

## S5 CSP, no third party, MIME e2e. MEM-078

- Playwright e2e on the map page; `mimetypes.add_type("application/vnd.pmtiles", ".pmtiles")`.
- CRITERIA: (1) web and native CSP strings equal their pre-map values; (2) 0 `securitypolicyviolation` events during
  load, pan, zoom; (3) 0 requests to a non-page origin; (4) 0 request URLs matching a lat/lon pattern; (5) extract
  Content-Type == `application/vnd.pmtiles`; (6) worker URL same-origin (no `blob:` worker).
- SIGNALS: none.
