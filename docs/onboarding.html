Onboarding guide

📄MemriPal onboarding#

A place-based recall coach for speeches: study points pinned to stops on a walk you know, recalled aloud, checked by deterministic code.

ELI5#

You have a talk to give. MemriPal ties each point to a place on a walk you know, draws a silly picture for each place, then listens while you walk it in your head and say the points. It tells you which ones you forgot.

WHY#

Building a memory palace by hand is slow and self-checking is unreliable. MemriPal automates the build with Meta models and keeps judging model-free, so a paraphrase cannot talk its way into a pass (ADR 0008). Built for the Meta Global AI Developer Hackathon (Oct 26 - Nov 4 2026).

WHAT#

  • Stateless FastAPI backend (src/memripal/app.py::create_app@h46203aac); palaces, routes and rehearsals live in the browser (ADR 0003).
  • Vanilla ES-module frontend in static/, no build step; page wiring in static/flow.js:151@h9770af0c.
  • Modes fixture (default, offline replay) and meta (live API), picked by src/memripal/backend.py::select_backend@hc1241b9b.
  • Direction is route-first (ADR 0038); the served Load demo still runs the room-photo chain until plan step B10 (ADR 0040).

HOW: core logic#

  • Loci: src/memripal/loci.py::find_loci@ha9e0fdb1 gets Spark phrases and SAM boxes; src/memripal/loci.py::select_loci@hba799d24 and src/memripal/loci.py::route_order@h636749ea pick and order them with no LLM.
  • Split: list mode src/memripal/split.py::split_list@h0495acc9; notes mode, one Spark call plus one regeneration, src/memripal/split.py::split_notes@hffee42f8.
  • Associate: src/memripal/associate.py::validate_association@h83acf155 checks records; src/memripal/associate.py::associate@h68000bc3 regenerates at most twice, then invalid.
  • Signing: src/memripal/record_sign.py::sign_record@h5edfb9b0; /scenes renders only records passing src/memripal/record_sign.py::sig_ok@ha2044792.
  • Recall: Levenshtein 0.8 or 60% coverage (static/recall_match.js:5-6@hfe3a890c) in static/recall_match.js:139@h15683138; live lighting relays 5 s slices (static/recall_live.js:7@hc4d69590).
  • Routes hold 3-8 stations (static/route_store.js:28-29@h14ec9f79); the Kendall demo route is frozen code (static/demo_route.js:15@h1f2f12a6).

HOW: data provenance#

  • Replays in fixtures/replay/ keyed by src/memripal/backend.py::RequestKey@h53469c95 or legacy src/memripal/backend.py::CacheKey@h19661f99; a miss raises in src/memripal/backend.py::FixtureBackend@h0cdbe15e.
  • Live calls write to gitignored refs/private/live-cache (ADR 0017).
  • Demo inputs are synthetic (fixtures/MANIFEST.md); uploads are re-encoded, EXIF-stripped (src/memripal/imaging.py::process_upload@he12c147e).
  • Wikipedia place text (CC BY-SA 4.0), opt-in only: src/memripal/place.py::PlaceProvider@h4981c888.
  • Backups carry no coordinates, 8 MiB cap (static/palace_export.js:14@h9109ef78).

HOW: gotchas#

  • /station and /baseline routers are not mounted by create_app (src/memripal/routes_station.py::make_station_router@hca85b376, src/memripal/routes_baseline.py::baseline_router@h9453b53d).
  • CORS unwired (src/memripal/cors.py::add_cors@h3e407690): the Android shell cannot reach the API yet.
  • src/memripal/stt_provider.py::select_stt_provider@hdf37e953 has no app caller; /recall/audio always uses Muse.
  • static/db/ SQLite worker (static/db/client.js:1@hb0f07ec9) has no non-test caller; stores use IndexedDB.
  • README is stale for the route-first flow: its intro ("starts from one photo"), pipeline diagram and the pyproject.toml description still describe the room-photo chain. Trust ADR 0038/0040 over README.
  • scripts/check.sh skips scripts/*.test.mjs; only npm test runs them.
  • The docs-sync pre-commit gate needs $AW/githooks/pre_commit_docs_sync.py; until that agent-workflow change lands every commit here fails closed.
