## MEM-003 Logical-key write-through cache + fixture replay

- **Superseded by MEM-014:** `CacheKey` frozen dataclass(method: str, photo_sha: str, subject: str, attempt: int = 0,
  prompt_version: str = PROMPT_VERSION). Now derived from a `ModelRequest` and also carries model id + gen-params
  digest; photo_sha is never caller-supplied.
- `CacheKey.digest() -> str`: sha256 hex of json.dumps(asdict(self), sort_keys=True, separators=(",", ":")).
  Equal fields -> equal digest; any field change -> different digest. No auth/request-bytes field exists.
- `ResponseCache(root: pathlib.Path)`: `put(key, body: bytes) -> pathlib.Path`, `get(key) -> bytes | None`.
  Layout: root / key.method / f"{key.digest()}{EXT[key.method]}", EXT = {"segment": ".txt", "spark_json": ".json",
  "image_edit": ".webp"}. Unknown method -> ValueError.
- `FixtureBackend(root)`: segment(photo_sha, phrase, attempt=0) -> str (utf-8); spark_json(photo_sha, subject,
  attempt=0) -> dict (json.loads); image_edit(photo_sha, subject, attempt=0) -> bytes.
- Miss -> `FixtureMissing` (subclass of LookupError), message includes method and digest.
- **Superseded by MEM-014:** `ModelBackend` is a typing.Protocol with those three methods. Now the Protocol is
  `call(req: ModelRequest)`; the three positional methods remain as shims that build a `ModelRequest`, so MEM-003
  callers and tests are unchanged.
- Exceptions live in memripal.backend.

Tests: tests/test_backend.py::TestCacheKeyDigest, ::TestResponseCache, ::TestFixtureBackend

## MEM-004 Pre-commit scan

`python scripts/precommit_scan.py <paths...>` exits 1 with a stderr line naming each offending path if any file:
- matches a secret pattern: r"\bsk-[A-Za-z0-9_-]{20,}" (word boundary: in-word sk- such as reask-... is not a key),
  r"Bearer\s+[A-Za-z0-9._-]{20,}", r"Signatur[e]=", r"[?&]token=",
  r"META_API_KEY\s*=\s*['\"]?[^\s'\"]{8,}" (the Signature pattern is bracketed here so this doc does not trip the scan);
- is a .jpg/.jpeg whose bytes contain an APP1 Exif segment (b"Exif\x00\x00");
- is a .png/.webp containing b"Exif" / an eXIf chunk.

Exit 0 when clean; missing path ignored. Wired by .githooks/pre-commit (runs on
`git diff --cached --name-only --diff-filter=ACM`) + README step `git config core.hooksPath .githooks`. Test fixtures
with planted keys are built in tmp_path at runtime, never committed.

Tests: tests/test_precommit_scan.py::TestPrecommitScan

## MEM-006 Meta HTTP client

`src/memripal/meta_client.py`; httpx is a runtime dep. API facts (dev.meta.ai/docs, fetched 2026-10-26):
- Base https://api.meta.ai/v1, header `Authorization: Bearer <key>`.
- Chat: POST /chat/completions {"model":"muse-spark-1.3","max_completion_tokens":N,"messages":[{"role":"user",
  "content":[{"type":"text","text":...},{"type":"image_url","image_url":{"url":"data:image/jpeg;base64,..."}}]}],
  "response_format":{"type":"json_schema","json_schema":{"name":...,"strict":true,"schema":{...}}}}.
  JSON string at choices[0].message.content.
- SAM: POST /responses {"model":"sam-3.1","input":[{"type":"message","role":"user","content":[{"type":"input_text",
  "text":"<phrase>"},{"type":"input_image","image_url":"data:image/jpeg;base64,..."}]}],
  "metadata":{"include_confidence":"true"}} (no stream). Text: top-level "output_text" if present, else concatenation
  of output[*].content[*].text (path unverified). Box token `<|box;x1=353;y1=382;x2=453;y2=427;w=537;h=561|>`,
  optionally `;c=0.91`, any key order. Zero matches = empty text.
- Image edit: POST /images/edits {"model":"muse-image-1.0","prompt":...,"images":[{"image_url":"data:..."}],"n":1,
  "output_format":"webp"} (+ optional "size":"WxH"). Image at data[0].b64_json.
- Errors: {"error":{"message","type","param","code"}}. Retry 429/500/503 + transport errors/timeouts; never retry
  400/401/402/403/404/413/504. Retry-After header (seconds) honoured on 429/503.

Contract:
- `CallResult` frozen dataclass: ok: bool, status: int | None, body: bytes, error: str | None, attempts: int,
  latency_s: float. ok iff final status 2xx. error = "<status> <error.code or 'http_error'>" or
  "transport: <ExcClass>"; never contains the key.
- `MetaClient(api_key: str, *, base_url="https://api.meta.ai/v1", timeout=60.0, transport=None, sleep=time.sleep,
  rand=random.random, max_retries=2)`. Empty api_key -> `memripal.backend.MissingApiKey`. repr/str = "MetaClient()".
- `post(path: str, payload: dict) -> CallResult`: JSON POST with bearer header. Retryable (429, 500, 503, httpx
  TimeoutException/TransportError): up to max_retries extra attempts (attempts <= 3). Delay before retry n (n=0,1):
  Retry-After int seconds if present and parseable (capped at 60), else 0.5 * 2**n; plus jitter rand() * 0.5.
  sleep called once per retry with that delay. Non-retryable status returns immediately (attempts == 1).
- `chat_json(*, prompt: str, schema: dict, schema_name: str, image_data_url: str | None = None,
  max_completion_tokens: int = 1024, model="muse-spark-1.3") -> CallResult`: payload exactly per API facts;
  strict true; image part only when image_data_url given; max_completion_tokens always present.
- `segment(*, image_data_url: str, phrase: str, model="sam-3.1") -> CallResult`: payload per API facts.
- `image_edit(*, image_data_url: str, prompt: str, size: str | None = None, model="muse-image-1.0") -> CallResult`:
  payload per API facts; "size" key only when given.
- Pure helpers: `chat_content_json(body: bytes) -> dict` (json.loads of choices[0].message.content);
  `responses_text(body: bytes) -> str` (output_text, else joined output[*].content[*].text, else "");
  `image_bytes(body: bytes) -> bytes` (base64-decode data[0].b64_json); `to_data_url(jpeg: bytes) -> str`
  ("data:image/jpeg;base64,...").
- Tests offline only: httpx.MockTransport, injected sleep/rand.

Tests: tests/test_meta_client.py

## MEM-007 SAM box parsing + edit drift

`src/memripal/probe_metrics.py`:
- `Box` frozen dataclass(x1, y1, x2, y2: int; w, h: int; confidence: float | None); `area` property
  (x2-x1)*(y2-y1).
- `parse_boxes(text: str) -> list[Box]`: every `<|box;...|>` token, key=value pairs any order; c -> confidence else
  None; token missing any of x1,y1,x2,y2,w,h is skipped; empty text -> [].
- `largest(boxes) -> Box | None`; `iou(a: Box, b: Box) -> float`.
- `keep_loci(per_phrase: dict[str, list[Box]], img_w: int, img_h: int) -> list[tuple[str, Box]]`: per phrase take
  the largest box; drop if area < 0.5% or > 40% of img_w*img_h; dedupe in descending area order, dropping any with
  IoU > 0.5 against an already-kept box. Returned in descending area order.
- `drift_outside_bbox(orig: bytes, edited: bytes, box: Box, scale: float = 1.5) -> float`: decode both (Pillow),
  resize edited to orig dims, mean abs diff over RGB channels (0-255, no grayscale) of pixels OUTSIDE the box scaled
  by `scale` about its centre (clamped to image). Identical images -> 0.0. All pixels inside -> 0.0.
- `crop_for_edit(jpeg: bytes, box: Box, min_side: int = 512) -> bytes`: JPEG crop of box + 25% margin each side,
  grown to at least min_side per side where the image allows, clamped to image bounds.

Tests: tests/test_probe_metrics.py

## MEM-008 Live probe

`src/memripal/probe.py` + `scripts/probe_live.py`. Claude never runs live mode; tests use a mocked MetaClient.
`run_probe(client: MetaClient, photo_jpeg: bytes, *, clock=time.perf_counter, audio_wav: bytes | None = None) -> dict`
(audio_wav: optional ASR check, MEM-011), in order:
1. Spark phrase list: chat_json with image, schema {"phrases": array of string}; prompt asks 20-25 short concrete
   noun phrases of distinct objects/places visible in the photo.
2. SAM per phrase (sequential), parse_boxes on responses_text.
3. keep_loci; if < 10 kept, ONE re-ask Spark round (prompt lists kept phrases to exclude) + SAM on the new phrases,
   merged and re-kept. Report `reask_used`.
4. One association: chat_json (no image), schema {"item","locus","scene"} all strings, item "toothbrush", locus =
   first kept phrase (skipped with reason if none kept).
5. Tier-1 edit on whole photo for the first kept locus, prompt "add a giant toothbrush at the <phrase>; keep
   everything else exactly as is"; record output dims, latency, drift_outside_bbox.
6. Tier-2 edit on crop_for_edit of the same locus; record output dims, latency.

Report:
- Keys "phrases", "kept_loci" (list of {phrase, box}), "kept_count", "reask_used", "calls" (list of {kind, ok,
  status, attempts, latency_s, error}), "checks" with exactly the 5 plan checks: "schema_image_ok" (bool),
  "parser_installs" (bool: `importlib.util.find_spec("meta_sam_parser")` is not None), "score_present" (bool: any
  parsed box has confidence), "image_output_dims" ([w,h] or null), "drift_metric" (float or null).
- Any failed call is recorded, never raised; later steps depending on it record null.
- Never contains the key or raw image bytes.

`scripts/probe_live.py --photo <path> [--out <dir>] [--audio <wav>]`: key ONLY from env META_API_KEY (missing -> stderr message +
exit 2, no file read); default out `fixtures/raw/probe/<UTC timestamp>/` (gitignored by fixtures/raw/**); writes
report.json + tier1.webp/tier2.webp when present; prints kept_count and checks. Exit 0 if run completed.

## MEM-012 Image intake

`src/memripal/imaging.py`: MAX_UPLOAD_BYTES = 15 * 1024 * 1024, MAX_PIXELS = 40_000_000, MAX_SIDE = 8000,
LONG_SIDE = 2048.
- `ImageRejected(ValueError)`: str(exc) = reason code; `.status` 413 for "too_large", else 400.
- `sniff(data) -> "jpeg" | "png" | "webp"` by magic (`FF D8 FF`, `89 50 4E 47 0D 0A 1A 0A`, `RIFF....WEBP`); anything
  else, incl. truncated magic -> "bad_magic".
- `process_upload(data) -> Processed` (frozen: jpeg: bytes, width, height: int, sha: str). Checks in order: "empty"
  -> "too_large" (> MAX_UPLOAD_BYTES; exactly 15 MiB passes) -> "bad_magic" -> "pixel_bomb" (w*h > MAX_PIXELS or a
  side > MAX_SIDE, read from the header before any decode). Then EXIF orientation applied, RGB, long side downscaled
  to LONG_SIDE (never upscaled), JPEG q90 with no EXIF/ICC/comment; sha = sha256 hex of jpeg. Any Pillow decode
  error -> "decode_error".
- Orientation-6 300x100 -> 100x300, no `Exif\x00\x00` APP1 in output. 4000x3000 -> 2048x1536; 800x600 unchanged;
  same input twice -> same sha.
- `validate_processed(data) -> Processed`: same empty/size/magic/header checks, then "not_jpeg", "has_exif" (APP1
  Exif), "too_big_side" (long side > LONG_SIDE). Never re-encodes: `jpeg is data`, sha = sha256(data).
  `validate_processed(process_upload(x).jpeg)` returns identical bytes and sha. For S3/S4 re-validating the
  client-returned photo (re-encoding is non-deterministic across rounds).

Tests: tests/test_imaging.py

## MEM-013 Locus selection

`src/memripal/loci.py` (pure); MEM-007 `keep_loci` unchanged.
- `Locus` frozen(n: int, label: str, phrase: str, box: Box, outline: list[tuple[int, int]]); outline = the 4 bbox
  corners.
- `sanitize_box(box, img_w, img_h) -> Box | None`: scaled via `scaled_to`; None unless 0 <= x1 < x2 <= img_w and
  0 <= y1 < y2 <= img_h (out-of-frame, negative, zero-width, w=0 frame rejected).
- `select_loci(per_phrase, img_w, img_h, *, min_loci=10, max_loci=12, spacing=0.05) -> list[tuple[str, Box]]`, in
  order: (1) area filter 0.5%..40% inclusive (keep_loci integer math) on every box; (2) per phrase largest = primary,
  rest = spares; (3) IoU > 0.5 dedupe over primaries, descending area; (4) centroid distance < spacing * diagonal ->
  keep the larger; (5) only while fewer than min_loci remain, add spares largest first that pass (3) and (4);
  (6) cap to max_loci by area.
- One phrase with 3 valid boxes + 7 other phrases -> 10 loci incl. all 3 books; + 12 other phrases -> at most one
  book. Centroids 3% of diagonal apart -> 1 kept (larger); 6% -> 2. 13+ survivors -> exactly 12.
- `disambiguate(selected) -> list[tuple[label, phrase, box]]`: label = last word of phrase, lowercased; a label
  appearing k >= 2 times is prefixed by centroid-x position: k=2 "left/right", k=3 "left/middle/right", k > 3
  "<noun> 1..k" left to right. Phrase unchanged. S3 validates against the full label ("left book").
- `route_order(items, img_h)`: sort by centroid y; new row when centroid y exceeds the row's first centroid y by
  more than 10% of img_h; rows top to bottom, left to right within a row; n = 1.. in that order. 2 rows x 3 jittered
  boxes -> n=1..6 top-left to bottom-right.

## MEM-015 POST /loci

`src/memripal/app.py`. Body = raw image bytes. Checks in order, before any body read:

  request returns 400.
- 200 JSON: {"image": "data:image/jpeg;base64,...", "width", "height", "photo_sha", "reask_used", "loci": [{"n",
  "label", "phrase", "box": {"x1","y1","x2","y2"}, "outline": [[x,y],...]}]}; image carries no EXIF.
- ImageRejected -> its status + {"error": code}; FixtureMissing -> 404 {"error": "fixture_missing"};
  BackendCallFailed -> 502 {"error": "upstream"}; any other exception -> 500 {"error": "internal"}, logged

## MEM-018 Architecture decision log

`docs/decisions/NNNN-slug.md` (NNNN = 4 digits, slug `[a-z0-9-]+`), indexed by `docs/decisions/README.md`:
- Each ADR has `Status:` and `Date:` lines and the headings Context, Options considered, Decision, Why this over
  the others, Consequences, exactly in that order.
- Options considered: >= 2 options (`- ` bullets), each with a `Pros:` and a `Cons:` line. Single-option exception
  only for ADR 0005 (key custody) and 0009 (image intake), and only when the section says "Alternatives not
  formally evaluated"; the marker on any other ADR does not lower the minimum.
- README links every ADR; every README link resolves to an existing file; ADR numbers unique and contiguous from
  0001.
- Missing heading/Status/Date, headings out of order, one option, option without Pros or Cons, unlinked ADR,
  dangling link, numbering gap, duplicate number -> each fails.

## MEM-019 Local Whisper STT provider toggle

ADR [0015](../../../../docs/decisions/0015-local-whisper-stt-toggle.md). Dev/offline only; judged path stays Muse
(MEM-011, ADR 0008).
- `select_stt_provider()`: env MEMRIPAL_STT_PROVIDER = "meta" (default) | "local"; other -> error.
- `LocalWhisperClient`: URL host must be loopback, else rejected; multipart POST `/v1/audio/transcriptions`
  (OpenAI-compatible, faster-whisper server); `SttCallFailed` message omits the response body.
- `local_stt_client_from_env()`: URL from MEMRIPAL_LOCAL_STT_URL. Mocked transport only.
